# KirbyDeck Changelog

All notable changes to KirbyDeck will be documented here.

---

## Version 1.0.0
- First Official Release 🎉🎉🎉
- Adds Button Sound Effect
- Adds disclaimer to ROM selection screen

## Beta 0.2.3

- Fixed an issue where the intro demo could incorrectly unlock certain ability cards
- Fixed an issue where ability cards could be used during the intro demo, potentially manipulating or breaking the demo
- Fixed an issue where the Fire ability card could incorrectly unlock during the loading screen
- Miscellaneous tweaks and bug fixes

## Beta 0.2.2

- Added support for additional versions of the Kirby's Adventure ROM
  - US
  - US Rev 1
  - EU
- Added a **Change ROM** button to Settings
- Miscellaneous tweaks and bug fixes

## Beta 0.2.1

- Added vibration / haptic feedback
- Added stylized pixel-art borders and icons to panels and buttons
- Added a rainbow LED effect for the Hyper Power-Up and Mix Card
- Ability cards are now disabled during game states where changing abilities could crash or interfere with the game
- Added additional features to the debugging tools

## Beta 0.1.1

- Fixed an issue where the bottom screen remained visible when KirbyDeck was minimized
- Fixed the Tornado ability
- Fixed an issue where the Sleep ability card could crash the game
  - Sleep still doesn't actually make Kirby sleep... yet
- Replaced gray Settings buttons with pixel-art arrow icons
- Added a **Report Feedback** button to Settings
- Improved ability switching behavior
- Miscellaneous bug fixes and improvements

## Beta 0.1.0
**Known Issues**
- Cards crash game if opened during the title screen or loading screens
- Cards automatically unlock while going through the intro tutorial
- The Fire card unlocks during the first load screen
- The Tornado card and Sleep card both crash the game
- Sometimes abilities don’t persist through doorways
- The subtract health UI breaks in the overworld screens
